# Little Archer: Monster Rush

เกมแนว survivor บนมือถือ: นักธนูตัวจิ๋วต้องเอาตัวรอดจากฝูงสัตว์ประหลาด เก็บ XP เพื่ออัปเกรดอาวุธ ล้มบอส และปลดล็อกแมพใหม่

**เล่นได้ที่: https://little-archer.vercel.app** (เปิดบนมือถือได้เลย ไม่ต้องติดตั้ง ไม่ต้องล็อกอิน)

---

## วิธีเล่น

| เรื่อง | รายละเอียด |
|---|---|
| เดิน | ปุ่มเดินอยู่กลางด้านล่างของจอ แตะที่ปุ่ม (หรือใกล้ ๆ) แล้วลากนิ้วไปทางที่อยากเดิน ปุ่มไม่ขยับตามนิ้ว |
| โจมตี | ฮีโร่ยิงเองอัตโนมัติ ไม่ต้องกดอะไร |
| เลเวลอัป | เก็บคริสตัล XP ที่ศัตรูทิ้งไว้ พอหลอด XP ด้านบนเต็ม จะได้เลือกอัปเกรด 1 จาก 3 ใบ |
| บอส | บอสโผล่ทุก ๆ 5 นาที ล้มได้จะได้หีบสมบัติ (อาจได้ "อาวุธวิวัฒนาการ") |
| ปลดล็อกแมพ | ล้มบอสตัวแรกของแมพไหน แมพถัดไปจะเปิดให้เล่น |
| จบรอบ | เล่นไปเรื่อย ๆ จนตาย เงินที่เก็บได้ไม่หาย เอาไปซื้ออัปเกรดถาวรที่ Shop |
| ภารกิจรายวัน | ปุ่ม Quests ในเมนู: วันละ 3 ภารกิจ (เปลี่ยนตอนเที่ยงคืน) + โบนัสเมื่อทำครบ ทุกรอบที่เล่นนับรวมให้ ทำเสร็จกลางรอบจะมีป้ายเด้งบอก แล้วกดรับเหรียญในหน้า Quests (ลืมกดรับ วันถัดไปเกมจ่ายให้เอง) |
| สุ่มการ์ด/ตัดการ์ด | หน้าเลเวลอัปมีปุ่ม Reroll (สุ่มการ์ดใหม่ทั้ง 3 ใบ) และ Banish (แตะแล้วเลือกการ์ดที่ไม่อยากเห็นอีกในรอบนั้น) รอบละ 1 ครั้ง ซื้อเพิ่มได้ใน Shop |
| รูน | การ์ด RUNE เปลี่ยนวิธีที่ทุกอาวุธทำงาน: ไฟลุกติดตัว (Ember), แช่แข็ง (Frost), สายฟ้ากระโดด (Storm), กระสุนเด้งต่อ (Bounce), ศพระเบิด (Blast), ดูดเลือด (Leech) ใส่ได้ 3 อัน อันละ 3 ขั้น |
| เหตุการณ์สุ่ม | ราวนาทีละครั้ง: แท่นบูชา (เลือกพรหรือคำสาปแลกรางวัล), ก็อบลินขนสมบัติ (มีลูกศรชี้), ฝนอุกกาบาต (หลบวงแดง), ฝูงอีลีท (ล้มหมดได้หีบ), ช่วงเหรียญทอง |
| ชนะ | บอสที่มานาที 15:00 คือบอสสุดท้าย ล้มได้คือผ่านด่าน (STAGE CLEAR) ได้เหรียญโบนัส |
| ความยาก | ผ่านด่านแล้วเปิด Hard บนแมพนั้น ผ่าน Hard แล้วเปิด Nightmare (มอนอึดและแรงขึ้น เหรียญมากขึ้น) เลือกที่ปุ่มบนการ์ดแมพ |
| เครื่องราง | ผ่านแต่ละแมพบน Normal / Hard ได้เครื่องรางจากบอส 6 ชิ้น ใส่ได้ 2 ชิ้นที่ปุ่ม Relics แต่ละชิ้นเปลี่ยนกติกา เช่น เริ่มพร้อมรูน, ฟื้นเต็มเลือด, หีบให้ของเพิ่ม |
| ความสำเร็จ | แท็บ Achievements: เป้าหมายระยะยาว 9 อย่าง แต่ละอย่างมีหลายขั้น (I, II, III...) รับเหรียญได้ทุกขั้น |
| หยุดเกม | ปุ่มม่วงมุมขวาบน (เกมจะหยุดเองด้วยถ้าสลับไปแอปอื่น) |

### ตัวละคร
เลือกที่ลูกศรซ้าย/ขวาข้างตัวละครในเมนู ตัวที่ยังล็อกอยู่ ปุ่ม PLAY จะกลายเป็นปุ่ม Unlock (จ่ายด้วยเหรียญ)

| ตัวละคร | อาวุธเริ่มต้น | จุดเด่น | ราคา |
|---|---|---|---|
| Little Archer | Bow | สมดุล | ฟรี |
| Little Mage | Magic Bolt | วงโจมตีกว้างขึ้น 15% แต่เลือดน้อยลง 10% | 600 เหรียญ |

### แมพ
1. **Sunny Meadow** ทุ่งหญ้า: Slime, Bat, Mushroom, Puffball (ตายแล้วแตกเป็น 2 ตัวเล็ก), ฝูง Buzzbee / หัวหน้า Boar Chief (พุ่งชน) / บอส King Slime
2. **Spooky Graveyard** สุสาน: Skeleton, Ghost, Zombie, Pumpkin Bomb (วิ่งมาระเบิด), Wraith (ยิงลูกวิญญาณ) / หัวหน้า Bone Captain (พุ่งชน + เรียกโครงกระดูก) / บอส Lich
3. **Dark Castle** ปราสาทมืด: Imp (ยิงไฟ), Armored Knight, Gargoyle (พุ่งชาร์จ), Mimic (แกล้งเป็นหีบสมบัติ ตีแตกได้เหรียญเยอะ), ฝูง Flame Wisp / หัวหน้า Ogre Warden (ทุบพื้นเป็นวง) / บอส Demon Lord

หัวหน้าโผล่นาที 2:30, 7:30, 12:30 ... ล้มได้หีบสมบัติ (อัปเกรด หรืออาวุธวิวัฒนาการ) ส่วนบอสยังมาทุก 5 นาทีเหมือนเดิม

### อาวุธและการวิวัฒนาการ
ถืออาวุธได้ 4 ชิ้น และไอเทมเสริมได้ 4 ชิ้น อัปได้สูงสุด Lv5 ถ้าอาวุธถึง Lv5 และมีไอเทมคู่กัน เปิดหีบบอสครั้งถัดไปอาวุธจะวิวัฒนาการ

| อาวุธ | ทำอะไร | Lv5 + ไอเทม | ร่างวิวัฒนาการ |
|---|---|---|---|
| Bow | ยิงธนูทะลุใส่ศัตรูที่ใกล้ที่สุด (มีตั้งแต่เริ่ม) | Quiver | Storm Bow |
| Magic Daggers | ปามีดใส่ศัตรูใกล้ ๆ หลายตัว | Hourglass | Thousand Blades |
| Spinning Axes | ขวานหมุนรอบตัว | Power Gem | Titan Axes |
| Holy Aura | วงแสงทำดาเมจรอบตัว | Heart | Sanctuary (ฮีลเลือดได้) |
| Lightning | ฟ้าผ่าศัตรูบนจอ | Storm Rune | Thunderstorm (ฟ้าผ่ากระโดดต่อ) |
| Fire Bomb | ระเบิดวงกว้าง | Blast Rune | Meteor (อุกกาบาตตก จุดไฟ) |
| Boomerang | ขว้างออกไปแล้วกลับมา | Bounce Rune | Twin Moons (บูมเมอแรงคู่รอบตัว) |
| Magic Bolt | ลูกเวทวิ่งไล่ตามศัตรูเอง (อาวุธเริ่มของ Mage) | Spell Tome | Starfall (ดาวตกใส่ศัตรูทั้งจอ) |
| Frost Shards | ยิงเศษน้ำแข็งเป็นพัด ศัตรูที่โดนเดินช้าลง | Winged Boots | Blizzard (พายุหิมะรอบตัว) |
| Moon Slash | ฟันเป็นวงพระจันทร์ด้านหน้า (Lv3 ฟันด้านหลังด้วย) ผลักศัตรูกระเด็น | Ember Rune | Flame Crescent (ฟันไฟสองข้าง) |
| Poison Flask | ขว้างขวดยาพิษ เกิดบ่อพิษทำดาเมจต่อเนื่อง | Leech Rune | Plague Cloud (บ่อพิษใหญ่ ทำให้ช้า) |

## เคล็ดลับสำหรับ iPhone

- **ให้เป็นแอปเต็มจอ:** เปิดลิงก์ใน Safari → กดปุ่ม Share → **Add to Home Screen** จะได้ไอคอนเกมบนหน้าจอ และเปิดแบบเต็มจอ
- **ไม่ได้ยินเสียง?** เช็กสวิตช์เงียบข้างเครื่อง (Silent mode) ถ้าเปิดอยู่ iPhone จะปิดเสียงเกมในเว็บ และต้องแตะจอ 1 ครั้งก่อน เสียงถึงจะเริ่มเล่น
- เปิด/ปิดเพลงและเสียงเอฟเฟกต์แยกกันได้ที่ปุ่มมุมซ้ายบนของเมนู หรือในหน้าหยุดเกม
- ความคืบหน้า (เงิน, อัปเกรด, แมพที่ปลดล็อก, สถิติเวลา) เก็บไว้ในเครื่องที่เล่น ถ้าล้างข้อมูล Safari จะหาย

## อยากปรับเกม? สั่ง Claude Code ได้เลย

ไม่ต้องแก้โค้ดเอง พิมพ์บอก Claude Code เป็นภาษาธรรมดาได้ เช่น

- "ศัตรูเยอะไป ลดจำนวนที่เกิดลงหน่อย"
- "เพิ่มเลือดเริ่มต้นของฮีโร่เป็น 150"
- "ให้บอสโผล่ทุก 3 นาทีแทน 5 นาที"
- "ราคาอัปเกรดในร้านแพงไป ลดลงครึ่งหนึ่ง"
- "เพิ่มอาวุธใหม่: ลูกไฟที่ยิงวนเป็นเกลียว"

ตัวเลขสมดุลทั้งหมดรวมอยู่ในไม่กี่ไฟล์ Claude จะหาเจอเอง:

| ไฟล์ | เก็บอะไร |
|---|---|
| `src/config/game.ts` | ค่าพื้นฐานฮีโร่ (เลือด, ความเร็ว, ระยะดูดของ), เวลาบอส, จำนวนศัตรูสูงสุด, มูลค่าเหรียญ |
| `src/config/weapons.ts` | ดาเมจ/คูลดาวน์ของอาวุธแต่ละเลเวล, ไอเทมเสริม, การวิวัฒนาการ |
| `src/config/enemies.ts` | เลือด/ความเร็ว/ดาเมจของศัตรูและบอส |
| `src/config/shop.ts` | อัปเกรดถาวรและราคา |
| `src/config/characters.ts` | ตัวละครให้เลือก: อาวุธเริ่ม, ราคา, ตัวคูณเลือด/วงโจมตี |
| `src/config/events.ts` | เหตุการณ์สุ่ม, พร/คำสาปของแท่นบูชา, เวลาบอสสุดท้าย |
| `src/config/difficulty.ts`, `src/config/relics.ts` | ความยากแต่ละระดับ และเครื่องราง |
| `src/config/maps.ts` | มอนแต่ละแมพ, มอนเสริม (`extras`), ฝูง (`swarm`), หัวหน้า (`leader`) |
| `src/config/quests.ts` | ภารกิจรายวัน (เป้าหมาย/รางวัลตามจำนวนแมพที่ปลดล็อก) และความสำเร็จ (ขั้นและรางวัล) |
| `src/core/waves.ts` | ความยากที่เพิ่มขึ้นตามเวลา (เลือดศัตรู, อัตราเกิด, ช่วง "คลั่ง" หลังนาทีที่ 8) |
| `src/core/progression.ts` | XP ที่ต้องใช้ต่อเลเวล และการสุ่มการ์ดอัปเกรด |

ทุกครั้งที่ Claude push โค้ดใหม่ขึ้น GitHub แล้ว deploy ลิงก์ด้านบนจะอัปเดตตาม

## สำหรับนักพัฒนา

เทคโนโลยี: Phaser 3 + TypeScript + Vite (เป็นเว็บล้วน ไม่มี server) ภาพหลักเป็นภาพวาด (WebP ใน `public/art/`) ส่วนที่ยังไม่มีภาพวาดใช้ SVG ที่เขียนในโค้ดแทน

```bash
npm install
npm run dev          # เปิดเกมที่ http://localhost:5173
npm run build        # typecheck + build ไปที่ dist/
npm test             # unit tests (Vitest)
PW_CHROMIUM=/path/to/chromium npm run test:e2e   # smoke test บนจอ iPhone จำลอง (Playwright)
```

**สวิตช์ทดสอบใน URL** (ใส่ต่อท้ายลิงก์):

| สวิตช์ | ผล |
|---|---|
| `?autostart&map=2` | ข้ามเมนู เข้าแมพที่ 2 ทันที |
| `?autostart&time=290` | เริ่มที่นาที 4:50 (ใกล้บอส) |
| `?god` | ไม่ตาย |
| `?bot&speed=8` | ให้บอทเล่นเอง เร่งความเร็ว 8 เท่า (ใช้ปรับสมดุล) |
| `?level=15` | เริ่มที่เลเวล 15 (สุ่มอัปเกรดให้) |
| `?gold=1000&unlock` | ตั้งเงิน และปลดล็อกทุกแมพ |
| `?debug` | แสดง FPS และจำนวนศัตรู |
| `?give=slash5,flask3,starfall` | เริ่มพร้อมอาวุธที่ระบุ (เลขท้าย = เลเวล; ชื่อร่างวิวัฒนาการ = ได้ร่างนั้นเลย) |
| `?hero=mage` | เล่นเป็นตัวละครนี้โดยไม่ต้องปลดล็อก |
| `?give=burn2,chain3` | (ใน give) ชื่อรูน + เลขขั้น |
| `?event=shrine` | เริ่มเหตุการณ์นี้ทันที (shrine, goblin, meteors, elites, golden) |
| `?difficulty=1&relics=boar,demon` | เล่นด้วยความยาก 0/1/2 และใส่เครื่องรางที่ระบุ |

สคริปต์ช่วย:
- `scripts/sim.mjs` ให้บอทเล่นแล้วรายงานเวลารอด/เลเวล/บอส (ใช้ปรับความยาก)
- `scripts/shot.mjs` ถ่ายภาพหน้าจอเกมบน iPhone จำลอง
- `scripts/art-sheet.mjs` + `art.html` ดูภาพ SVG ทั้งหมดในหน้าเดียว
- `scripts/make-icons.mjs` สร้างไอคอนแอปจากภาพฮีโร่
- `scripts/build-artifact.mjs` build เป็นไฟล์ HTML ไฟล์เดียว (ไม่มีเสียง, ฝังภาพใน `public/art/` ไว้ด้วย) สำหรับแชร์แบบ artifact

**งานภาพ** (ลุคเกม MMORPG เกาหลียุค 2000 ออกแบบใหม่ทั้งหมด):
- `npm run art:openai -- <out.png> --prompt <file> --ref <ภาพ>` สั่ง OpenAI วาด 1 ภาพ (key เก็บเป็น network secret ของ environment; มีเพดานงบใน `art/openai-log.jsonl`)
- prompt อยู่ใน `art/prompts/mr_*.txt`, ภาพต้นฉบับใน `art/incoming/mr/`, ภาพต้นแบบลุค `art/incoming/mr/look_mockup.png`
- `npm run art:cut` ตัดแผ่นภาพเป็น texture ขนาดเกม ตาม `scripts/art/mr-sheets.json` → `public/art/<key>.webp` + `src/art/manifest.json`
- ฮีโร่เป็น sprite sheet ที่ bake จาก puppet ของโปรเจกต์ Sky Pirates (`scripts/art/hero-bake/`); ภาพตัวละครในเมนูตัดจากภาพ master ด้วย `npx tsx scripts/art/menu-still.ts <master.png> <out.webp>`
