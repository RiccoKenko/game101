# Little Archer: Sky Pirates

เกม 2.5D บนมือถือ แนว Tower Defense ผสมเกาะ Idle นักธนูน้อยปกป้องเกาะลอยฟ้า Sky Haven จากโจรสลัดอากาศที่มาขโมย Sky Crystal ภาพเป็นแนวอนิเมะแบบเกม MMORPG เกาหลียุคก่อน

**สถานะตอนนี้: 2D-1 (หน้าโชว์ตัวละคร)** เปิดลิงก์เกมแล้วจะเจอหน้าโชว์ตัวละคร ยังไม่ใช่ตัวเกมเต็ม
- **Hero:** Little Archer มี 10 ท่า และปุ่มเปลี่ยนสีหน้า
  - ท่า: ยืน, เดิน, วิ่ง, ยิงธนู, ยิงรัว, พุ่งหลบ, โดนตี, ล้มสลบ, เชียร์, เรียกสกิล
  - แตะตัวฮีโร่แล้วจะเชียร์
- **Story:** ตัวอย่างฉากเล่าเรื่อง เป็นกล่องบทสนทนาที่มีภาพครึ่งตัว ภาพเปลี่ยนตามอารมณ์ และฮีโร่ทำท่าตามบนเวที
- **Battle:** ยิงเป้าซ้อม
  - หางแสงลูกธนู, เป้ากระพริบขาวและโยก, ประกายไฟ, ตัวเลขดาเมจเด้ง
  - hit-stop, จอสั่น, slow-motion
  - เหรียญกระเด็นแล้วดูดเข้าตัว
  - Sky Burst

**ด่านทดลอง `/play.html` (2D-2 → 2D-3):** ด่าน 1 เล่นได้แล้ว 8 เวฟ
- แผนที่ด่าน 1 เป็นภาพวาดจริงแล้ว (Codex วาดทับภาพร่าง) ส่วนโจรสลัดและป้อมยังเป็นภาพวาดด้วยโค้ดชั่วคราว
- **วิธีเล่น**
  - แตะจุดหินเพื่อสร้างป้อม แตะซ้ำเพื่ออัปเกรดหรือขาย
  - แตะพื้นหญ้าแล้ว Little Archer จะวิ่งไป พอยืนนิ่งจะยิงเอง
  - ลากเพื่อเลื่อนจอ ถ่างนิ้วเพื่อซูม ปุ่ม ×2 เร่งเวลา
- **ป้อม 4 แบบ** อัปเกรดได้ถึงระดับ 3 แล้วเลือกสายที่ระดับ 4 (ป้อมละ 2 สาย)
  - Archer Tower: ยิงเร็ว ยิงตัวบินได้
  - Cannon: ลูกปืนใหญ่ระเบิดโดนหลายตัว แต่ยิงตัวบินไม่ได้
  - Storm Crystal: ฟ้าผ่าทะลุเกราะ ยิงตัวบินได้
  - Frost Cloud: คลื่นความเย็นทำให้ทุกตัวในระยะเดินช้าลง (ไม่ทำดาเมจ)
  - สายระดับ 4:
    - Archer: Sniper Nest (ยิงไกลมาก คริแรง) / Volley Tower (ยิง 3 ดอกพร้อมกัน)
    - Cannon: Mortar (ไกล ระเบิดวงใหญ่) / Flak Cannon (ระเบิดกลางอากาศ โดนตัวบิน)
    - Storm: Lightning Spire (สายฟ้ากระโดด 4 ตัว) / Arcane Lens (ลำแสงยิ่งจ้องนานยิ่งแรง)
    - Frost: Blizzard (วงกว้าง ช้าลงมาก และทำดาเมจเล็กน้อย) / Ice Shard (ยิงน้ำแข็ง แช่แข็งชั่วครู่)
  - ปุ่ม Target เลือกว่าจะยิงตัวไหน: ตัวหน้าสุด / ตัวใกล้สุด / ตัวที่แบกคริสตัล
- **โจรสลัด 4 แบบ**: Deckhand, Powder Monkey (เร็ว), Ironclad (เกราะกันธนูและปืนใหญ่ครึ่งหนึ่ง), Parrot Raider (บินได้)
- **บอส First Mate** (ท้ายเวฟ 8)
  - แบกคริสตัลทีเดียว 3 ก้อน
  - ตะโกนให้โจรรอบตัววิ่งเร็วขึ้น
  - ทนน้ำแข็ง: ช้าลงแค่ครึ่งเดียว และแช่แข็งไม่ได้
  - มีแถบเลือดบนจอ
- **กติกา**
  - โจรสลัดเดินจากท่าเรือไปขโมยคริสตัลที่คลังแล้วแบกกลับเรือ
  - ยิงโจรที่แบกคริสตัลอยู่ให้ตก คริสตัลจะลอยกลับคลังเอง
  - ถ้าคริสตัลถูกขนออกไปหมดถือว่าแพ้ ได้ดาวตามจำนวนคริสตัลที่เหลือ

ต่อไป: ใส่ Deckhand ตัวจริงและแผนที่ที่วาดแล้ว, สกิล Talon/Mochi และการ์ดคำสั่งกัปตัน

## ตัวละครทำยังไง

1. **วาด:** เจ้านายให้ ChatGPT วาดตาม prompt ใน `docs/art/CHARACTER_BRIEF.md` ซึ่งได้ทั้งภาพหน้าตาและภาพแยกชิ้นส่วน
2. **ตัด:** `npm run art -- hero`
   - ลบพื้นหลัง แล้วแยกแต่ละชิ้นออกจากแผ่น
   - ทำภาพตรวจ `art/sliced/hero/<แผ่น>.check.png` ที่ตีกรอบและใส่เลขทุกชิ้น
3. **ประกอบ:** `art/rigs/hero.json` บอกว่าแต่ละชิ้นติดกับกระดูกไหน
   - ใช้วิธีระบุ 2-3 จุดบนภาพชิ้นส่วน แล้วบอกว่าจุดเหล่านั้นต้องไปอยู่ตรงไหนบนภาพ rig pose
   - ระบบจะคำนวณตำแหน่ง ขนาด และมุมของชิ้นนั้นให้เอง
4. **ส่งเข้าเกม:** `npm run art:publish -- hero` คัดลอกชิ้นส่วนและ rig ไปที่ `public/sprites/hero/`
5. **ขยับ:** ท่าทางเขียนเป็นโค้ดใน `src/puppet/clips/hero.ts`
   - ระบบตุ๊กตากระดาษ (`src/puppet/`) จัดการเรื่องพวกนี้ให้:
     - IK สำหรับง้างธนู
     - สายธนูจริง
     - ผ้าคลุมและปลายฮู้ดสะบัดด้วยสปริง
     - กะพริบตา
     - สลับสีหน้า

| โฟลเดอร์ / ไฟล์ | มีอะไร |
|---|---|
| `art/incoming/<ตัวละคร>/` | ภาพต้นฉบับจาก ChatGPT ตั้งชื่อตามคู่มือ เช่น `hero_parts_body.png` |
| `art/sliced/<ตัวละคร>/` | ผลการตัดภาพ ซึ่งสร้างใหม่ได้เสมอจึงไม่เก็บใน git |
| `art/rigs/<ตัวละคร>.json` | การประกอบตัว: กระดูก, ชิ้นส่วน, ลำดับการวาด, สปริง, จุดสายธนู |
| `scripts/art/sheets.json` | รายชื่อชิ้นส่วนของแต่ละแผ่นตามลำดับใน prompt (แผ่นหน้ามีกรอบกำหนดเอง) |
| `public/sprites/<ตัวละคร>/` | ชิ้นส่วนที่เกมใช้จริง |
| `src/puppet/` | ระบบตุ๊กตากระดาษ 2D บน Three.js |
| `src/showcase/` | หน้าโชว์ตัวละคร |
| `src/td/` | กติกาของด่าน TD ล้วน ๆ ไม่มีการวาด: เส้นทาง, คลังคริสตัล, เวฟ, การเลือกเป้า, เงิน, การจำลองการต่อสู้ (`battle.ts`) |
| `src/td/levels.ts` | ข้อมูลด่าน: จุดทางเดิน, จุดวางป้อม, เวฟ, เงินเริ่มต้น เป็นพิกัดบนภาพแผนที่ |
| `src/play/` | หน้าด่านทดลอง: อ่านค่าจาก `battle.ts` แล้ววาดออกมาพร้อมเอฟเฟกต์ |
| `art/maps/` | ภาพร่างแผนที่ที่วาดจากข้อมูลด่าน ใช้แนบให้ Codex / ChatGPT วาดทับ |
| `art/incoming/maps/`, `public/maps/` | แผนที่ที่วาดเสร็จ (ต้นฉบับ / ไฟล์ที่เกมใช้) |

## สำหรับนักพัฒนา

เทคโนโลยี: Three.js (โหมด 2D ใช้กล้อง orthographic) + TypeScript + Vite เป็นเว็บล้วน ไม่มี server

```bash
npm install
npm run dev                  # เปิดที่ http://localhost:5173 (หน้าโชว์ตัวละคร), /play.html (ด่านทดลอง)
npm run map:sketch -- level1 # วาดภาพร่างแผนที่จาก src/td/levels.ts และตรวจว่าจุดป้อมไม่ทับทาง
npm run art -- hero          # ตัดภาพจาก art/incoming/hero/ ไปที่ art/sliced/hero/
npm run art:publish -- hero  # ส่งชิ้นส่วน + rig ไปที่ public/sprites/hero/
npm run build                # typecheck + build ไปที่ dist/
npm test                     # unit tests (Vitest)
PW_CHROMIUM=/opt/pw-browsers/chromium npm run test:e2e   # smoke test บนจอ iPhone 15 แนวนอน
```

เครื่องมือช่วย:
- `dev/rig.html?clip=shoot&t=0.2,0.45`: ดูหลายเฟรมเทียบกัน
  - `frames=dodge@0.2,hit@0.1`: ผสมหลายท่าในภาพเดียว
  - `overlay=0.5&joints=1`: ซ้อนภาพ rig pose และแสดงข้อต่อ
- `dev/reel.html`: เล่นทุกท่าต่อกัน
  - `node scripts/record.mjs out.mp4 /dev/reel.html`: อัดเป็นวิดีโอ
- `scripts/shot.mjs`: ถ่ายภาพหน้าจอบน iPhone จำลอง (`/?battle` เริ่มโหมดต่อสู้ทันที)
- `npm run showcase:artifact -- out.html`: รวมหน้าโชว์เป็นไฟล์ HTML ไฟล์เดียว
- `npm run play:artifact`: รวมด่านทดลองเป็นไฟล์ HTML ไฟล์เดียว (`sky-pirates-play.html`)
- `/play.html?seed=3`: ล็อกการสุ่มให้เล่นซ้ำได้เหมือนเดิม
